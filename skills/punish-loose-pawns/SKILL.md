# 抓松散兵（punish-loose-pawns）

对方出现无保护、或保护不足的兵（尤其是中心兵和冲得过远的边兵）时，这就是本回合的目标。抓弱点优先于一般发展、优先于"求稳"退子。

## 要点

1. 每个回合先扫一遍对方的兵：**每个兵有几个子保护？** 找出保护者少于攻击者的兵。重点看 d5/e5/d4/e4 中心兵，和冲到 a5/b5/g5/h5 的边兵。
2. 中心兵脱保 → 立刻吃。例：黑 d5 兵失去足够保护，白方直接 exd5 得兵扩大物质优势。**不要**走 Ba2、Bd3、Be2 这类退让/重整的缓着把机会让掉。
3. 边兵冲得过远、无子保护 → 立刻吃，而且往往顺带打开攻王线路：Nxg5、gxh3、Bxb5、Kxh3、Qxh5、Qxg5 都是这类着法。对方王城被这些兵削弱后，吃掉它们等于同时拿到物质和线路。
4. 自己的王也能吃兵。若 Kxh3 之后王安全（对方没有后续将军/子力围攻），就用王吃，不要因为"王不该出门"而放过。
5. 吃之前算清三件事：吃子本身是否安全（不被更低价值子攻击、不被牵制）；吃完对方能否用等值或更低价值的子夺回（数攻击者 vs 保护者）；吃完我是否被将军或被杀棋威胁。
6. 弱兵被牢固保护、一时吃不到时，改为**持续施压**而不是兑子释放压力。例：西西里交换变种，黑 e5 兵后，9.dxc6 是错的，应走 Nb5 压 c7，让对方的 c 线弱点一直疼。
7. 有免费吃兵时，别去走无保护的王翼兵推进（如 g5），那既送兵又削弱自己的王翼；先 Nxe4 之类的取利着法。

## 典型错误

- 有免费兵不吃，走 Ba2 / Bd3 / Bd2 之类退子或"先出子"的机械着法。
- 看到对方边兵冲上来只想到防守，没想到它已经无保护、可以直接吃掉并开线。
- 用兑子（dxc6）处理对方的弱点，反而帮对方解决麻烦；应该用马、后加压。
- 只算"我能不能吃"，不算"吃完他能不能吃回来"，结果白丢子。
- 有更强制的手段（将军、杀棋、吃更大的子）时，机械地先吃兵。

## 检查清单

1. 对方每个兵各有几个保护者？哪个兵保护最少？
2. 我哪个子（包括王）能吃到它？
3. 吃完后我是否被将军、被反吃、被牵制？
4. 吃这个兵是否同时打开攻王线路或牵制对方子力？
5. 有没有比吃兵更强的着法（将军、杀棋、赢更大子力）？
6. 若吃不到，我能否用马/后加压这个弱兵，而不是兑子放它一马？
7. 我有没有顺手走出削弱自己王城或送兵的无谓之着（如无保护的 g5）？
