**核心判断**：王暴露（未易位、已离开王城、王前兵被推走）且对方车/后等重子活跃时，杀机常在一两步内出现。此时任何“顺手”的进攻、吃兵、推边兵都要让位给王的安全。

**要点**
1. 先算将军：列出对方车、后、象、马对我王的全部将军着法与后续（车在开放线/次底线、象的斜线、马步格）。没算清不走棋。
2. 选安全格：王优先移到不被将军、且换线后仍少受攻击的格子；避开对方车所在的开放线，以及它下一步能占的线。宁可花一步走王，也不要花一步吃兵。
3. 补后排：车留在底线或关键线上防守；用一子守住被攻击的入点。王前务必留一个逃格，别让自己的子堵死。
4. 兑掉攻击子：能用后/车兑掉对方最活跃的重子（尤其对方只剩一车时），兑子本身就是防守。
5. 完成易位或建屏障：还能易位且易位后王更安全就立刻易位；不能易位就用子力在王前构成屏障。

**典型错误**
1. 连续推进 a/h 边兵或贪吃边兵，忽略后排，被车+象、车+后配合将杀。
2. 王沿开放线移动（躲到对方车所在的线上），或走到对方下一步能将军的格子。
3. 该易位时不易位，等对方重子集中到王翼才补防，已经来不及。
4. 把防守子调离关键斜线/线，或用自己的子占掉王的唯一逃格。

**检查清单**（每步落子前）
1. 对方有哪些将军？我这步会不会放开或忽略它们？
2. 走完后我的王是否仍在开放线或对方重子的射程内？
3. 后排有没有能被车/后直接侵入的格子？谁在守？
4. 我的王还有逃格吗？王前是否被自己的子堵死？
5. 对方最活跃的重子能否被兑掉？
6. 我是否还在贪一个与王安全无关的兵？
