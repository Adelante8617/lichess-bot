象、车、后沿线打击。同一条线上隔着一个子，就有线性战术。

1. 牵制：长兵器 → 对方子 → 对方更值钱的子（或王）。被钉在王前的子不能动（绝对牵制），被钉在后前的子动了就丢后。用法：再加一个子攻击被钉的子（尤其用兵），它跑不了；不要急着兑掉钉住的子。
2. 串击：顺序反过来，长兵器 → 对方值钱的子 → 后面的子。值钱的子（常是王、后）被迫让开，后面的子被吃。
3. 闪击：长兵器 → 自己的子 → 对方目标。挪开中间的子就露出攻击；挪开的子同时去攻击 / 将军 / 吃子，就是一步两个威胁。闪将（露出将军）时挪开的子可以去任何地方吃子，几乎必赚；双将只能走王应对。
4. X 光：隔着对方子"透"过去控制后面的格，常见于同线叠车、车后叠后，交换完最后一下是我的。
5. 炮台：后象同斜线（瞄 h7）、双车同线，火力叠加。

反过来（防守）：对方走开一个子，先看它身后有没有车象后的线被打开（闪击）；我的王、后、车不要和对方的长兵器同线、中间只隔一个子；被钉住的子不要当作保护者，它不能动。

赛后统计：暂无。
