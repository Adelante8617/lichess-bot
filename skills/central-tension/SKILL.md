# 中心张力（central-tension）

中心兵链互相顶住时，这盘棋的胜负多半取决于谁先破坏张力、谁被迫兑兵。

## 要点

1. 先算清兑兵后果：谁先兑、兑完打开哪条线 / 斜线、对方哪个子因此活起来。算不清就别兑。
2. 中心兵被攻击（受压）时，第一优先是防守要害或反顶中心（...d5 / ...e5 / ...c5），不是顺手出子、吃边兵。
3. 占优时保持张力：保留 c5 对 d4 这类张力、用 b5 之类扩后翼空间，比过早 cxd4 简化更好。简化让对方的防守变容易。
4. 对方在翼上进攻（如白 b4 冲后翼）时，最有力的回应通常是用中心反击 ...d5，而不是跟着在翼上被动防守。
5. 中心未稳时不要贸然兑子、也不要把中心子撤退；先把子力放到能支撑中心的格，再谈计划。

## 典型错误

- 中心兵被攻击，却去发展子力 / 吃边兵 → 被对手战术打击，失子失势（此类失误已出现 2 次）。
- 中心未稳就贸然换子或撤退 → 中心拱手让人，全局被动。
- 白方 b4 后中心未稳，黑方没走 ...d5 反击中心 → 被动挨打。应对原则：遇翼攻先想中心反击。
- 中心有 c5/d4 张力时过早 cxd4 兑兵（Δ约 53cp），正确是 b5 保持张力、扩后翼空间。原则：占优时保持中心张力、逐步扩空间，优于过早简化。

## 检查清单

1. 我的中心兵被几个子攻击？我能加几个保护？守得住吗？
2. 有 ...d5 / ...e5 / ...c5 的中心反击吗？走之前算清兑兵后打开哪条线、谁受益。
3. 我这步兑兵是必须的，还是只是为了"简化"？占优就别兑，先扩空间。
4. 中心未定时，我是否在贪翼兵、撤中心子或出无关的子？
5. 对方在翼上动手了——我有没有先检查中心反击？
