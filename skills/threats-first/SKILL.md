轮到我走时先做威胁检查：我方是否有子被攻击、对方上一步是否吃子。有威胁就先解决，再谈出子、易位和计划——"在执行计划"不是无视威胁的理由。过往对局里最常见的失误，就是明明有子被攻击却走了一步无关的兵着 / 出子 / 易位，白丢一子。

1. 先算吃回。对方刚吃子落在我方兵/子能回吃的格子，先算清交换，能等价或净赚就吃回，别让对手先手逃子。兵能回吃时优先用兵（bxc3 优于 Qxc3），避免后暴露在开放线上。
2. 能吃掉攻击者就吃。攻击我方的子若无保护、价值更高、或深入己阵悬着，直接吃它通常比逃好；只挪走被攻子会让它逃掉并反吃。先算清它正攻击哪个子，再决定。
3. 逃之前查落点：会不会被兵斜吃、被马跳吃、仍在同一条线 / 斜线上被车象后攻击。只躲开眼前一个攻击、却走进另一个，是反复出现的错误。逃的同时带将或带威胁（攻击对方子 / 无根子）最好。
4. 消威胁优先于发展。轻子被兵攻（如 e5 兵攻 f6 马）先 Nd5 / Nfd7 或兑掉威胁；子被钉住、或退路被己方车挡住时，先解钉、移开挡路车或用后保护，再谈出子。
5. 别走无关着。有子被攻击时走无关兵着、出子、易位是头号失误；王或后兼守关键子时不要随手动它们。
6. 重子与车。车同线互攻时先吃车或兑掉，别横向逃到同线；对方车 / 后侵入牵制（如 Rb2 牵 e2 象）先撤象或驱车，别贪边角小兵；对方后形成叉子时，用带先手的攻击（如车攻后）逼其离开，再吃回受攻子。
7. 换子要算净账。中心马被攻击且王翼薄弱时，先用兵反击或防守，别贸然跳马换子丢子；轻子被兵威胁时别用车远守（只能兑回一兵，等于丢子），应逃子或等价交换；双方兵互攻（如 f5 对 e4）时先吃掉受攻兵，别走边兵。

赛后统计：暂无。
