认得杀王图形，才会算出来，也才知道该提前防。

1. 底线杀：王在底线、前面兵没动（没有"透气孔"），车或后打到底线就杀。进攻：引离守底线的车（将军、弃子）。防守：走一步 h3 / h6（或 g3 / g6）开透气孔，或保持车守底线，别让守底线的车被引走。
2. 闷杀：王被自己的子围住，马将军即杀（Nf7#、Qg8+ Rxg8 Nf7#）。
3. 希腊式弃象：白象 d3、马能到 g5、后能到 h5，黑王 g8 且 h7 只有王守，Bxh7+ Kxh7 Ng5+ 后 Qh5。前提是黑 f6 没有马守 h7、黑方没有快速防守子。
4. 后象 / 后马杀 h7（g7）：后和象（或马）同时瞄 h7，王前缺守。
5. 阿拉伯杀：车和马配合，马控角格旁边（车 h7 + 马 f6 杀 h8 王）。
6. f7 / f2 弱点：开局只有王守，象后、马后组合（Bxf7+、Ng5 打 f7）。

识别：数对方王身边的格：几格被自己的子堵住、几格被我控制、还剩几格可逃。只剩 0-1 格就找将军。
反过来（防守）：我方王被堵在底线、王前兵被拆时，先补透气孔或加防守子，再执行计划。

赛后统计：暂无。
