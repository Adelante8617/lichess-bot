过往被将杀，多是王翼经典杀型，且往往是自己先拆掉了防线。

1. 后 + 象在 b1-h7（b8-h2）斜线、或后 + 马（马在 g5 / g4）同时瞄 h7（h2）：这是 Qh7# 杀型。对策是封斜线（...g6 / ...f5）、增援 h7（马回 f6、象回 e7 / f8、车让出 f8 给王）。此时禁推 h6 赶马——赶不走马，还可能把斜线完全让开（典型：留出 g6 空格即被 Qh7#）。
2. 算杀先看对方将军的落点是否被其子力保护：被保护时我方王不能吃，"这格有两个子保护"也没用；我方"多子保护"在对方有保护时同样无效。先算强制线路、解掉杀棋，再谈反击。
3. 不要为了吃一个子而打开王前的线：gxh3 / gxf3 会打开 g 线，对方后和车沿 g / h 线集结后就是 Qg2#。王翼未安时也别用象换 g2（g7）兵贪兵，尤其对方有 Bxh7+ 类闪击时。
4. 王前的兵（f2 g2 h2 / f7 g7 h7）是屏障：对方后贴近时，g2（g7）兵往往是防 Qxg2# 的唯一子，不要随意 g3（g6）让开；gxf6 之类造成的兵形破损、h7 孤立同样致命。
5. 防守王城的子（f6 马、e7 象、f8 车）没有充分理由不要调走；斜线、开放线与要害格优先用车补防（车横移 / 沉底护格），它一离开，原本被它挡住的威胁立刻出现。
6. 对方的后、车、马开始往王翼集结时提前准备：兑掉最危险的进攻子（尤其兑后）——但只有兑后能真正消除威胁且不吃亏时才兑，否则先封线、增援、Kh1 / ...Kh8 让位，或在中心反击牵制。对方后已能将军王时，停止边翼扩展，先 ...f5 / ...h6 造气（仅作通气，不用于赶马）、封闭将军线。
7. 王翼受压时优先协调防守子力、用兵封线阻断对方后路，不要消极等待、贸然弃子或走无关的边翼棋；对手摆出 f4 / g4 型兵结构时，提前布防。

赛后统计：暂无。
